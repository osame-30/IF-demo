# IF（デモ）— Word・Excelの取り込みと履歴確認

**資料を繰り返し取り込んでも、原本・版・抽出結果の対応を保ち、何を処理したか確認できるローカルツールです。**

Word（`.docx`）の本文・表、Excel（`.xlsx`）のシート・セル・数式・保存値を抽出し、原本の版と位置へ辿れます。文書取り込みを自作する開発者向けのソース公開デモです。

## まず架空資料で試す

Node.js 22.13以降の22系、または24系とnpmを用意します。Word・Excelアプリ、Python、LLM、APIキーは不要です。

```sh
git clone https://github.com/osame-30/IF-demo.git
cd IF-demo
npm ci --ignore-scripts
npm run demo:parse
```

端末に出たローカルURLをブラウザで開きます。Windows PowerShellでnpmの実行を拒否される場合は `npm.cmd` と入力してください。終了は Ctrl+C。

毎回、新しい一時フォルダに架空のWord・Excelと意図的に壊したWord、保存用DBを作ります。「文書・中身」→「中身・履歴を見る」で対象を開き、「内容を解析」から抽出結果を確認できます。正規化結果も作成でき、元の抽出位置・値へ戻れます。画面内の検索は選択した文書の正規化結果が対象です。

**試すポイント:** 同じ資料を再走査する／資料を書き換えてもう一度走査する／過去の版に戻る／壊れた資料の失敗理由を確認する。詳しい操作は [DEMO.md](DEMO.md)。

## できること

- ローカルフォルダの走査、差分・欠損の検知。削除反映は取り込み先の状態変更で、原本ファイルは削除しません。
- 原本の生バイト列をハッシュで識別し、保存・読取時に照合。
- 文書・原本版・解析・正規化成果物の対応を保持し、旧成果物も参照。
- 同じ入力・処理版・設定で結果を再利用。更新した資料は別の版として保持。
- ローカル運用画面で失敗・警告・履歴・整合性を確認。

無変更時にも走査・観測の履歴は増える場合があります。「100回でも副作用ゼロ」という保証ではありません。

## このデモの範囲

| 対象 | 内容 |
|---|---|
| Word | 本文の段落・表。ページの見た目や印刷レイアウトの再現ではありません |
| Excel | シート・セル位置・式・保存値。数式の再計算はしません |
| 上限 | 原本20MiB、ZIP展開32MiB、セル2万件など。詳細は技術的制約を参照 |
| 実行 | 1人で使うローカル運用。サーバーはloopback限定 |
| 含まない機能 | PDF解析、画像PDFのOCR、埋め込み、RAG、AIセッション検索、全PC自動取込み |

隠し文字・非表示セルを含む場合があります。Wordのヘッダー・フッター・画像・図形等は抽出対象外です。Excelの保存値が最新かどうかは保証しません。解析成功は全文の完全抽出を意味しません。上限を超える資料や未対応形式は処理できません。[KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md) に技術上の制約を記録しています。

別プロセスの解析器は同じOSユーザー権限で動き、OSの隔離環境ではありません。起動URLには認証情報が含まれるため共有しないでください。デモ用の一時保存先も終了後に残ります。

## 自分の資料で使う

初回は試験用コピーを別フォルダに用意してください。保存先を明示して起動します。

```sh
npm run ui -- --data-dir ./local-data --port 4318 --open
```

画面で資料フォルダを接続して走査します。保存先を走査対象フォルダ内に置かないでください。保存先には原本コピーとDBが残るため、リポジトリへ追加しないでください。これは新しい保存先で試す手順です。旧版DBの移行を自動で行いません。

## 開発・検証

```sh
npm run typecheck
npm test
```

テストには不正ZIP/XML、再実行、版・出典の対応、破損、削除安全弁、HTTP認証等を含みます。実施済みの範囲と未実施を [VALIDATION.md](VALIDATION.md) に分けて記録します。
